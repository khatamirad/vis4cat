Tip: group by source_file to see which dataset each point came from.
A Y axis (left/right) plots another column against the current X, on its own scale. An X axis (top) plots the current Y column against a different X column instead. Extra-axis series aren't split by Color/group by.
Rows sharing the same X (and split columns, if any) are treated as replicates and aggregated. Checks above the chart flag hidden condition variation, uneven replicate counts, missing segments, negative values, and totals that don't sum sensibly — dismiss (✕) any check you've already accounted for.
Points are shown automatically for any group with fewer than 10 replicates, since a box or violin summary alone can be misleading at low n. Histogram doesn't support Group by — it always pools all rows per value column.
